# 伊豆交通文档

这份文档只整理你们这次四套行程真正会用到的伊豆交通信息，不追求把整个半岛所有线路都抄一遍。

重点只看 4 类问题：

- `东伊豆` 这一天，`伊豆高原站 / 海洋公园 / 城崎海岸 / 大室山 / 仙人掌公园` 到底怎么接。
- `南伊豆` 这一天，`伊豆急下田站` 该去哪个巴士站台。
- `西伊豆不包车` 这一天，`修善寺站` 去 `土肥` 用哪个站台。
- `东海巴士 伊东&伊豆高原 2 日券` 到底值不值得买。

## 1. 这次行程真正要记住的交通枢纽

### 伊豆高原站

- `伊豆高原站` 是东海巴士官方列出的主站点之一。
- 官方主站页写得很清楚：`伊豆高原站` 只有 `2 个站台`，而且 **站内没有东海巴士案内所**，所以别指望到站后再慢慢问，最好提前记好站台方向。
- 站台分工：
  - `1 号站台`：`仙人掌公园 / 赤泽海岸`
  - `2 号站台`：`伊东站 / 海洋公园`

对你们这次最有用的理解是：

- 去 `大室山 / 仙人掌公园`，先认 `1 号站台`。
- 去 `城崎海岸 / 伊豆海洋公园 / 门胁吊桥一带`，先认 `2 号站台`。
- 如果当天需要在 `海洋公园` 和 `仙人掌公园` 两边来回切，不要凭感觉乱找车，直接回到 `伊豆高原站` 当中轴最稳。

### 伊豆急下田站

- `伊豆急下田站` 是东海巴士官方列出的南伊豆主站点，也是你们 `南伊豆日` 最关键的换乘点。
- 官方主站页给出了完整站台号。和你们本次行程最相关的是：
  - `2 号站台`：`龙宫窟 / 田牛`
  - `4 号站台`：`石廊崎`
  - `7 号站台`：`下田海中水族馆`
  - `9 号站台`：`白滨海岸 / 河津方向`
  - `10 号站台`：`须崎海岸 / 爪木崎`

对你们这次最实用的结论是：

- 去 `白滨神社 / 白滨海岸`，先看 `9 号站台`。
- 去 `爪木崎`，先看 `10 号站台`。
- 要补 `龙宫窟`，看 `2 号站台`。
- 如果天气不好改去 `下田海中水族馆`，看 `7 号站台`。
- 包车版去 `石廊崎` 没必要研究公交；但如果临时改公交，站里要看 `4 号站台`。

### 修善寺站

- `修善寺站` 是西伊豆 / 中伊豆最关键的东海巴士主站点。
- 官方主站页写明：
  - `4 号站台`：`土肥温泉 / 堂ヶ岛 / 松崎`

对你们这次最重要的结论是：

- `不包车版西伊豆日` 到了 `修善寺站`，核心就是盯住 `4 号站台`。
- 这一线是长线，不是地铁心态。错过一班，后面半天经常会直接塌掉。

### 伊东站

- `伊东站` 不是你们这次每天都会用到的站，但它能帮助理解东伊豆巴士结构。
- 官方主站页里与你们最相关的是：
  - `2 号站台`：`川奈港 / 海洋公园 / 伊豆高原站`
  - `5 号站台`：`一碧湖 / Granpal / 仙人掌公园 / 大室山`

这说明东伊豆巴士本身就是分成两条大方向：

- `海岸 / 海洋公园 / 城崎` 一条线
- `大室山 / 仙人掌 / Granpal` 一条线

所以你们网站里现在写成“`伊豆高原站` 作为中轴，再决定先海岸还是先大室山”，这个逻辑是对的。

## 2. 东伊豆这一天怎么理解才不会乱

你们真正会用到的，不是“背完整线路名”，而是把它理解成下面这套：

- `伊豆高原站 2 号站台` 负责 `海洋公园 / 城崎海岸` 方向。
- `伊豆高原站 1 号站台` 负责 `仙人掌公园 / 大室山` 方向。

你给的散乱草稿 `伊豆高原站  至  城崎口` 里，还保留了几条很有价值的信息：

- 页面抓到的是 `I33` 相关线路页面。
- 截图当天能看到 `16:05`、`17:05`、`18:05` 这类班次。
- 乘车规则写的是：
  - `前门上车`
  - `下车时付款`
  - `可用 PASMO / Suica`
  - `也可现金支付`

这份草稿本身格式很乱，不能直接当最终时刻表，但至少能说明两件事：

- 东伊豆这条巴士线下午确实还有车，不是 15 点之后完全断掉。
- 但 `17:05` 这种已经非常接近你们真正会被卡住的时间线，所以网站里保留“`15:30-16:00` 前开始往回收”是合理的。

另外，NAVITIME 这条线的站点和换乘信息还说明了几个关键点：

- `城ヶ崎口`
- `蓮着寺口`
- `伊豆海洋公園`
- `伊豆高原駅`

都在同一条 `伊东站 - 海洋公园 - 伊豆高原站` 的东海巴士走廊上。

而且在：

- `蓮着寺口`
- `伊豆海洋公園`

可以接到：

- `[I70/72/82] 伊豆海洋公园 - 仙人掌公园`
- `[I71/80] 伊豆海洋公园 - Granpal - 仙人掌公园`

在：

- `ファミリーガーデン`
- `伊豆高原駅`

还能接到：

- `[I73] 伊豆高原站 - 仙人掌公园`

这对你们的实际意义不是“要去研究每一条编号”，而是：

- `海岸线` 和 `大室山 / 仙人掌` 之间确实可以靠巴士互相接。
- 但最稳的做法，依然是把 `伊豆高原站` 当中轴，不要在景点之间赌小换乘。

## 3. 南伊豆这一天怎么跑才不慌

你们网站里现在的核心逻辑是对的：`下田` 是中轴，按班次在 `白滨 / 爪木崎 / 龙宫窟 / 水族馆` 之间做减法。

真正落地时，只记住下面这个站台表就够了：

- `9 号站台`：白滨海岸
- `10 号站台`：爪木崎
- `2 号站台`：龙宫窟
- `7 号站台`：下田海中水族馆
- `4 号站台`：石廊崎

所以到 `伊豆急下田站` 后，最实用的动作顺序应该是：

1. 先看今天 `9 / 10 / 2 / 7` 这几个站台的回程时间。
2. 先做你们最在意的点。
3. 如果已经错过一段舒服的回程窗，就删减后面的加点。

这也是为什么你们网站里写：

- `14:30` 后别新开 `龙宫窟`
- `16:00-16:30` 前要开始往 `下田站` 收

这两句不是保守，而是符合南伊豆公交的真实节奏。

## 4. 西伊豆不包车这一天，为什么一定要减法

这次你们不包车版写成：

- `北川 → 热海 / 三岛 → 修善寺 → 土肥`

这个方向本身没问题。

关键是到了 `修善寺站` 后，你真正能靠的就是：

- `4 号站台` 的 `土肥 / 堂ヶ岛 / 松崎` 方向长线巴士

而不是“到了修善寺再看心情”。

这也是为什么网站里现在把西伊豆不包车版收成：

- `只保土肥 / 西海岸入口`
- `不硬冲堂ヶ岛`

因为 `修善寺 → 土肥` 都已经是一条需要早出、不能错车的长线，再想同一天把 `堂ヶ岛 / 黄金崎 / 恋人岬` 都塞进去，交通上很容易崩。

## 5. 东海巴士「伊东 & 伊豆高原 2 日券」怎么判断值不值

你给的第二份草稿 `东海巴士周游券`，和东海巴士官方页大体一致，整理后的重点如下：

### 官方信息

- 名称：`Tokai Bus Free Ticket "Ito/Izukogen 2-Day Ticket"`
- 成人：`1,800 日元`
- 儿童：`900 日元`
- `EMot` 数字票目前有儿童 `500 日元` 的活动价
- 有效期：`2 天`
- 销售点：
  - `Tokai Bus Ito Sta. Information Center`
  - `EMot`
  - `Seven Tickets`
- 不适用：
  - `顺天堂医院直通巴士`
  - `高速 / 急行巴士`
  - `Izu Amagi Resort shuttle`
  - `指定设施契约巴士`

### 对你们这次行程的实际判断

- 这张票更适合：
  - `伊东 / 伊豆高原` 一带连续两天主要靠巴士跑景点的人
  - 或者一天里会多次坐 `伊豆高原站 ↔ 海洋公园 ↔ 仙人掌公园 / 大室山` 这种巴士的人

- 这张票 **不适合直接理解成“整个伊豆都能用”**：
  - 你们 `南伊豆下田日`
  - `修善寺 → 土肥`
  - `下田 → 石廊崎`
  - 这些都不是这张票最核心的使用场景

所以对你们当前四套方案来说，结论是：

- **不是必买票**
- 最值得考虑的只有 `东伊豆那天如果大量坐巴士` 的情况
- 南伊豆和西伊豆那两天，不要指望靠这张票解决全部问题

### 这次更值得顺手一起比较的两类东海巴士票

- `伊豆高原 / 城崎 1 日票`
  - 东海巴士官方 `EMot` 页面确认这张票存在。
  - 它更贴近你们这次 `东伊豆单日` 的玩法，也就是 `大室山 + 城崎海岸` 这类以 `伊豆高原站` 为中轴的一天。
  - 所以如果只是做单日东伊豆，通常先看它，再看 `伊东 & 伊豆高原 2 日券`。

- `东海巴士全线 2 / 3 日券`
  - 官方也确认有这张票。
  - 但它只有在你们 `不包车版` 三天都大量坐东海巴士时，才值得认真比。
  - 如果你们最后还是以 `铁路 + 少量巴士 + 包车` 为主，通常不如 `直接刷 IC + 按需买单日票` 更直观。

## 6. 东海巴士现场执行规则

这个部分看似基础，其实很关键，因为你们这次会频繁在 `伊豆高原 / 下田 / 修善寺` 三类站点之间切。

- 出发前一晚和当天早上，各看一次 `东海巴士运行状态` 页面。
- 东海巴士官网会公告 `停运 / 绕行 / 临时改点`，但普通堵车延误通常不会详细写进去。
- 东海巴士路线巴士原则上支持 `全国交通 IC 卡`，但部分车辆除外，所以仍要备现金。
- 如果用 `IC`，就是 `前门刷卡上车`，不用拿整理券。
- 如果用 `现金`，就是 `前门上车拿整理券，下车时连同整理券一起付款`。
- 车上兑零只按 `1000 日元纸币` 理解；`5000 / 10000` 不要指望车上帮你处理。

## 7. 西伊豆还有一个官网明确写出来的备选

东海巴士官网单独有一页在讲：

- `西伊豆特急 / 快速巴士`

对你们这次真正有帮助的点是：

- 官网确认 `三岛站 ↔ 松崎` 有直通的 `西伊豆特急 / 快速巴士`。
- 它属于普通路线巴士体系，`不用预约`，也 `不用额外特急费`。
- 所以如果你们后面临时想把 `西伊豆减法版` 再往 `堂ヶ岛 / 松崎` 研究深一点，优先先看这条，不要只盯 `修善寺换乘`。

但这不会改变现在网站的成品方案：

- 当前不包车版仍然坚持写成 `修善寺 → 土肥` 的 `西伊豆入口减法版`
- 因为这才是对你们这次时间、体力和返程稳定性最友好的版本

## 8. 补充：伊豆急「探索通票」对你们有没有用

这张票和上面的东海巴士 2 日券不是一类东西。

- `东海巴士 2 日券` 管的是巴士。
- `伊豆急探索通票` 管的是 `伊东站 ～ 伊豆急下田站` 之间的 `伊豆急行铁路`。

官方页面写到的核心点是：

- 有 `2-Day / 3-Day` 两种版本。
- 可坐 `普通车（含快速）`。
- 可坐 `特急踊子号` 的 `空席`。
- 可在 `伊东市观光案内所`、`伊豆高原站`、`伊豆急下田站`、`伊豆热川站`、`伊豆稻取站`、`河津站` 这些点兑换实体票。
- 原则上 `不可退款`。

对你们四套方案的实际判断是：

- 这张票 **比东海巴士 2 日券更贴近你们的主干移动**，因为你们这次伊豆主轴本来就要频繁用到：
  - `伊豆北川 / 热川 ↔ 伊豆高原`
  - `伊豆北川 / 热川 ↔ 下田`
  - 部分版本还会考虑 `踊子号`

- 但它依然 **不是无脑必买**，因为：
  - 它 **不管东海巴士**。
  - `东伊豆日` 真正花得多的往往是景点接驳巴士，不是那几段短铁路。
  - `包车版 D6` 直接开车送站，这张票当天也帮不上什么。

所以更准确的结论是：

- **比东海巴士 2 日券更值得纳入比较**
- **但依然要按你们伊豆 3 天里实际会坐多少次伊豆急行来算，不是默认必买**
- 如果你们最后确定 `D4 东伊豆 + D5 下田南伊豆 + D6 晚上从伊豆高原/热海北上` 都主要靠铁路接驳，这张票就值得在出发前认真对比一次

## 9. `伊豆navi` 电子票入口有没有用

有用，但它的价值主要是 **买票方便**，不是替你们自动做票券判断。

JR 东日本的 `Izu navi` 页面说明了几件事：

- 可以在手机上买 `电车 / 巴士 / 景点` 的电子票。
- 也可以顺手看路线、地图和区域信息。
- 它会按 `东伊豆 / 南伊豆 / 中伊豆 / 西伊豆` 给出一些“推荐电子票券”。

对你们这次最实际的帮助是：

- 如果不想现场排队，或不想现场研究日文售票页面，`Izu navi` 可以当作一个方便的电子购票入口。
- 它比到了站再临时找纸票窗口更省心，尤其适合出发前一晚把票先收藏好。

但要注意：

- 它上面的推荐票是 **按区域泛推荐**，不是按你们这次四套行程精算后的建议。
- 比如页面会推荐：
  - `下田 2 日券`
  - `三岛 1 日券`
  - `堂岛 / 松崎 / 石廊崎 2 日券`
- 这些票不能因为“页面推荐了”就默认值得买，还是要回到你们当天到底跑几段、是不是包车、是不是只做减法版来判断。

所以最准确的定位是：

- **它值得放进工具箱**
- **但不值得替代你们已经定好的票券判断逻辑**

## 10. 对你们四套方案最实用的结论

### 东京+伊豆 / 箱根+伊豆 的 `东伊豆日`

- 先记 `伊豆高原站 1 号站台 = 大室山 / 仙人掌`
- 再记 `伊豆高原站 2 号站台 = 海洋公园 / 城崎`
- 如果开始担心末班，就优先删 `城崎` 的深步道，不要删回程窗

### 四套方案里的 `南伊豆日`

- 先记 `下田站 9 / 10 / 2 / 7 号站台`
- 白滨和爪木崎优先级通常高于龙宫窟
- 龙宫窟和水族馆更像天气或体力替补项

### 不包车版的 `西伊豆日`

- 真正关键点不是 `堂ヶ岛值不值得去`
- 而是 `修善寺站 4 号站台` 这一条长线能不能顺利接上
- 所以网站里现在坚持“`土肥减法版`”，是对的

### 包车版的 `中西伊豆日`

- 既然包车 `8 小时` 内可以灵活指挥，就没必要再拿公交逻辑束缚自己
- 这一天最该把力气留给：
  - `石廊崎`
  - `堂ヶ岛`
  - `黄金崎`
- `修善寺 / 伊豆全景公园` 是最后收口，不是不能删减的硬点
