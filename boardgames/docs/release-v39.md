# v0.39 · 联合推导与报告操作

2026-11-20。不清理对局、线索、历史分析、剧本或API Key。

## 联合推导

把人数配额从检查表升级为参与推导的通用约束：联合角色唯一性、私有身份、公开交互和最新声明，推导新身份、必在角色及一组位置中的恶魔/爪牙数量。新结论继续连接能力反馈，不固定先盘某个角色或剧本。

明确区分规则能证明的结论和依赖当前善良如实报身份的条件结论。考虑不自知、隐瞒风险、阶段、角色变化与特殊配置；条件矛盾时定位需要放宽的位置，不直接认证该人邪恶。相同事实缓存，设置可选计算预算，不增加前置LLM调用。

详见 [推理架构](../clocktower/docs/reasoning-v39.md)。

## 合并此前未发布的v0.38展示修复

当前报告上方的历史入口之前，只保留三个报告操作：导出请求json、导出报告md、复制报告全文。切换报告时对应其自身的请求，不误导出最新一局资料。完整复制与导出包含折叠部分，并去掉内部折叠标记。

修复整篇报告外层Markdown围栏、嵌套列表和有序列表。真正代码块保持安全显示。复制失败提供当前报告的手动复制文本，不替换报告。清理历史折叠区的重复预览及操作。

## 验证

335项钟楼检查、14项站点检查通过；包括140组容量匹配与完全枚举对照、不同类型名额推导及旧追问兼容。单HTML构建与内联脚本语法检查通过。此前v0.38展示修复已验证320/390/768/1440宽度无横向溢出；本版推理验证以本地案例和模拟协议为主，没有新增真实付费LLM评测。

用户报告TXT已用于还原案例；指定的原始请求JSON未找到，未声称逐项复现原请求。现有有界静态暗流求解器与通用结构约束各自保留适用边界，不宣称全剧本全机制穷举。
