# v0.34 · 全站复查与加载优化

## 已落实的流程

- 首页 → 桌游 → 狼人杀 / 钟楼；空工作区直接开局、取消返回桌游、已有对局继续使用。旧钟楼地址保留查询参数与片段跳转。
- 英语 / 钟楼共用本机个人 Key，支持粘贴、修改、清除；模型与思考偏好独立。跨标签页修改同步配置状态，不重建设置表单。
- 隐藏旅行页不加入公共导航；现有对局、脚本、词汇、角色数据不迁移、不清空。

## 本轮修复

- 五个分类共用原生站点导航，包含桌游入口、当前位置、键盘焦点管理与 Escape 返回。移除旧导航处理器和约 21 KB 废弃样式。
- 音乐：修复图标替换后折叠 / 全屏按钮查找失败；快捷键避开表单和按钮；列表支持键盘；切歌保持播放意图，进度清零；根据文件更新时长；错误以行内状态显示。
- 五十音：练习、答案选择、壁纸详情使用原生 dialog；选择题及下一题焦点接续；减少动态模式保留完整功能。
- 图库：分类数量来自实际项目，合并重复统计；移动端紧凑筛选；键盘可打开图片，原生灯箱保留原图和前后切换。
- 英语：支持 64 字符输入；分析状态跟随思考偏好；钟楼共用 Key 被清除后，两端状态即时同步。

## 加载策略

- 街霸、五十音、图库移除 Tailwind CDN 运行时，使用约 30 KB 本地编译 CSS；所有公共页面的字体、图标、核心脚本均可同源加载。
- 四个分类应用从 HTML 拆出独立缓存；脚本在 head 发现、defer 按依赖顺序执行，每页仅核心应用使用 high 优先级。初始化不等待整页图片或媒体加载。
- 31 张图库预览：3,790,890 → 1,298,912 字节，减少 65.7%；首图优先，其余延迟；原图仍在灯箱打开时读取。
- 音视频只在播放操作后设置 src；首个视频使用 11.9 KB 海报。初始浏览不下载整段媒体。
- 指针反馈只在精细指针、允许动态时启用；静止后停止 RAF，后台 / 弹窗 / 触屏停止。无新框架、WebGL 或音效依赖。

## 验证

- 网站整合 12 项；钟楼原有 312 项；狼人杀 11 组规则与 1,600 次随机发牌通过。
- 9 个公共入口在 320、768、1440 宽度无横向溢出，另检查 390 手机布局。浏览器实测导航、角色切换与数据页、五十音答题、图库筛选 / 原图、播放器静音播放 / 切歌 / 折叠、空钟楼开局 / 取消 / 继续、英语个人设置及共享 Key 清除。
- 仅在本地用无效测试 Key 验证粘贴与同步，未调用付费模型，未修改线上用户存储。此轮没有改动推理内核，自动检查不代表真实对局模型输出质量验证。

站点仍由 GitHub Pages 托管；本轮没有更改 DNS、CDN 或 Cloudflare Worker。上述为资源体积和加载机制改善，不将本地测试虚报为全球网络提速测量。

## 维护

```sh
npx --yes --package tailwindcss@3.4.17 tailwindcss -c scripts/tailwind.config.cjs -i scripts/utilities.input.css -o shared/utilities.css --minify
python scripts/build-gallery-previews.py
node --test tests/site.test.cjs
```

改动分类 HTML / app.js 中的工具类后重新编译 CSS。钟楼和狼人杀继续先构建同工作区源码，再运行 scripts/sync-game-tools.cjs；不要只修改发布的生成文件。
