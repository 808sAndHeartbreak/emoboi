# v0.36 · 恢复原站视觉

恢复原站字体、E标志、拼贴美术和切片反白导航。首页重回原有的宽体文字和红色全屏菜单；桌游、街霸、日语、英语、图库、音乐恢复各自的视觉语言。去除重复说明与无效装饰，不再以统一的哥特字体覆盖工具。

首页少量拼贴浮动，桌面指针移动时产生轻微视差，入口悬停与键盘聚焦联动美术。提供暂停按钮，并遵循减少动态偏好；指针静止、页面隐藏及打开菜单时停止指针循环。保留本地字体、WebP、媒体延迟加载、原生菜单和资源内容哈希。

音乐保留自然高度的可收起歌单、隐藏项焦点隔离和桌面双栏。钟楼恢复原正文字体与城镇背景；自称仍用黑白层级。玩家、线索、推理、剧本、Key和历史记录的存储逻辑未修改，未调用付费模型。隐藏旅行页面不加入公共导航。
