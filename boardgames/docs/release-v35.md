# v0.35 · 银、黑纸与血红

全站视觉采用统一的纸白 / 炭黑 / 少量血红，以原创银色哥特尖拱主视觉连接首页和桌游；入口使用哥特拉丁字，功能、线索、报告与设置使用清晰的系统黑体。保留各工具有用的角色、正确 / 错误等语义颜色。

## 页面

- 首页：一张原创主视觉，六个直接入口；移除原有 27 张装饰拼贴、滚动横幅、光标尾随及重复线框。原图库素材仍保留。
- 桌游：同一品牌、剪贴中文标题、两项明确入口，去除重复框线和符号。狼人杀开局、私密身份卡与主持界面统一纸面颜色、字号及动作按钮；钟楼保留圆桌、线索、推理页签与全部记录流程。
- 音乐：唱片式标题、安静的控制区、清楚的曲目层级，去除光晕、反复脉冲及旧绿条；媒体仍仅在播放时加载。歌单自然展开，收起同时禁用隐藏曲目的交互，避免嵌套滚动与误触；电脑采用播放器 / 歌单两列。
- 图库：展示图片本身，标题置于图下；取消覆盖图片的蒙层与重复装饰。
- 英语：一行输入 / 查询、扁平历史列表、统一个人 AI 设置；移除旧扫光和荧光边框。
- 街霸：保留角色主题用于有意义的信息标识，移除满屏角色背景、滚动封条和闪烁收藏提示；当前角色直接显示角色名，场景阅读更紧凑。
- 五十音：保留教学网格，字符采用系统明朝 / 宋体，读音及控件采用黑体；允许缩放，移除闪烁。
- 隐藏旅行：保留地图与纸面美术，统一正文与操作反馈；Leaflet 本地托管并延迟执行。仍不加入公共导航。

## 性能与维护

- 钟楼独立 HTML 从 2,879,002 降至 1,273,369 字节（减少 55.8%）：取消约 1.33 MB 内嵌正文字体，旧背景替换为 23.5 KB 主视觉；离线打开、角色资料和推理内核保留。
- 新首页 HTML 约 2.5 KB，手机主视觉 23.5 KB；哥特字体 20.7 KB，普通正文无字体下载。
- 去除全站指针 RAF、自动横幅、氛围层动画和无意义脉冲。保留一次进入、短距离切换、按压与状态颜色反馈；减少动态时提供静态表现。
- CSS 与 JS 引用按 SHA-256 内容加版本，避免新 HTML 引用浏览器缓存的旧脚本；没有变更的资源版本保持稳定。
- 网站测试合并为 `tests/site.test.cjs`。新增内容版本核验及独立包 / 美术体积预算，防止回退。

未改写现有对局、脚本、Key、词汇或旅行数据。未调用付费模型；本轮没有改动推理内核或模型定价，也未更改 DNS、CDN、Worker。

## 验证

钟楼312项、狼人杀11组及1,600次随机发牌、网站14项检查通过。浏览器检查10个模块在320 / 390 / 768 / 1440宽度无横向溢出，复测目录、图库筛选 / 原图、歌单折叠、静音播放 / 切歌、角色数据及原生弹窗。

## 维护顺序

1. 修改各分类 HTML / app.js 与 `shared/edition.css`。钟楼、狼人杀先在同工作区源工程构建。
2. 运行 `node scripts/sync-game-tools.cjs` 同步两款工具。
3. 工具类改变后重新编译 `shared/utilities.css`。
4. 最后运行 `node scripts/stamp-assets.cjs`；之后若再改 CSS / JS，需要再次运行。
5. 运行 `node --test tests/site.test.cjs`，检查手机 / 平板 / 桌面与真实交互。

资源和完整生图提示词见 [ART.md](../../asset/edition/ART.md)。旧版发布说明仅作变更历史，当前维护流程以本页和 README 为准。
