# v0.31 · 特殊角色开局与爬行都市

保留v0.30的恶魔优先、条件数量剪枝、报告缓冲后展示与深度思考进度。此轮更新开局配置、阶段确认和玩家资料。

## 阶段操作

天亮默认展开死亡号码，多选后确认；无人死亡仍须明确选择。入夜直接展示处决号码，保留无人处决、已记录处决和处决后仍存活。默认只是操作入口，不会预选某个号码、制造死亡或把“每天必有人死”作为游戏规则。关闭或返回不推进，空选不能通过。切换无人死亡会清空先前勾选，避免隐藏值误记。

号码使用原生单选/多选、fieldset与legend，48px触控区及可见键盘焦点；选择标记不改变无障碍名称。最多五列，12个号码自动四列。沿用原生dialog与showModal，背景滚动隔离为渐进增强。

## 开局选择

- 旅行者默认关闭；启用后选择实际座位。人数指全部座位，基础配比按非旅行者人数计算，死亡不释放名额。旅行者阵营不按角色类型自动推定，也不直接占用爪牙或恶魔名额。
- 传奇仅启用明确勾选的角色；基础传奇库补入哨兵、骗人精、玩具匠等12项。传奇不占玩家座位，不能选作本人角色，不因醉毒失效。原剧本自带传奇作为默认选择，可手动关闭；奇遇保留为剧本规则。
- 开局筛选只生成本局副本，不改常驻剧本。切换剧本保留各自草稿；备份恢复保留旅行者座位和启用的传奇。
- 普通处决列表排除旅行者，旅行者的特殊能力事件仍可通过线索和生死记录补充，不将流放视为普通处决。

模型输入包含travelerSeats、非旅行者基础配比和activeFabledIds。未选传奇不进入本局角色池；启用角色的技能和必要机制随普通分析提供，完整技巧仍只随深度思考提供。哨兵实际启用时生成其-1/0/+1外来者与男爵的联合配置，不产生负数；通常counts仅为调整前参考。

带旅行者或传奇的对局不冒充标准静态暗流核验，使用保留完整原文与实际规则的分析路径。暂不把中途加入或离场旅行者、所有传奇之间的组合实现为专用求解器。

## 剧本与资料

[爬行都市](https://ran.dogyupi.com/scripts?open=local-c9c33d90b5e3fc5a)，作者Aero；原始JSON于2026-11-17下载。完整保留14镇民、5外来者、5爪牙、1恶魔及原始附加规则。角色池数量不等于实际在场数量。常驻库现在为官三加四份预装，共七份。

源JSON的GstoneID与_button包装ID在技能兼容时恢复内置ID；改写技能保留原文，不强行认作标准版。哈迪寂亚依本次原始卡面及百科核对为“要选择三名”，不与旧版“可以选择”的技能混用。

以[新百科前缀](https://wiki.biligame.com/jbzlbwgwjcygf/)逐页核对本剧本25名角色，另补12个基础传奇页，共37页本轮资料；累计232页、233份玩家资料。重点整理：哈迪寂亚按实际生死结算、侍女的自身能力唤醒、哲学家真实身份与所获能力、理发师角色交换但不交换阵营、多来源醉毒与免死。策略仅作倾向；即使百科攻略存在过强措辞，也不据此认证玩家。

普通分析获取必要规则，深度模式再附完整玩家技巧与问答。没有复制说书人布置、唤醒操作或标记摆放流程。原文缓存仅本地，网站发布整理后的摘记和来源。
