## 钟楼手记

[打开钟楼手记](https://emoboi.com/clocktower/)。主页导航和全屏菜单均有“钟楼”入口。

```
clocktower/
├── index.html             # 自包含 HTML：界面、脚本、字体与背景
├── README.md              # 使用方式与数据说明
├── scripts/daybreak.json  # 重见天日图片整理版，可独立导入
├── scripts/storm.json     # 山雨欲来角色合集，自包含技能
├── scripts/temple-fair.json # 华灯初上角色合集，自包含技能
├── docs/player-reference.md # 角色资料来源、版本与输入边界
├── docs/script-json.md    # JSON标准与拍照识别流程
├── docs/analysis-v22.md   # 统一信息与推理流程
├── docs/analysis-v21.md   # 紧凑报告、候选分配与有效行动
├── docs/analysis-v20.md   # 分析流程、夜序与确定性边界
├── scripts/import-example.json # 可直接导入的混合角色示例
├── NotoSansSC-OFL.txt      # 界面黑体许可
└── NotoSerifSC-OFL.txt     # 标题宋体许可
```

首页展示“血染钟楼推理工具”和大号“开始”按钮，设置位于开始下方。开局直接配置新对局，历史对局在同窗折叠。默认 12 人、支持 5–20 座位；进入后由底部页签切换“游戏信息”和“推理分析”。游戏页为圆形座位、阶段和速记，存活亮/死亡暗，5–20人按需拉长椭圆；推理页可选模型、提问和开启新对话，历史按对话归组。角色选择维持稳定窗口、单层列表滚动；设置可退出本局。

通用补充规则与常驻剧本库保存在本机。开局可临时导入 JSON、调整角色和本局裁定；临时修改不覆盖剧本库。历史对局和自定义剧本支持删除、恢复。支持完整备份与手机操作，AI Key 由使用者自行配置。预装常驻“重见天日”（北方的预言家，图片整理版），含25个玩家角色、2个奇遇及完整特殊规则，用户修改与删除状态保留。

重新分析使用最新完整资料开启独立对话；追问沿所选报告继续，仅增量补充变化。支持历史报告分支、独立追问草稿、原始证据引用与返回阅读位置。局内为墨黑与纸色阅读界面，手机纵向、桌面游戏信息双栏；首页动效遵循减少动态效果设置。

v0.22统一自由速记、玩家声明与条件核算，原始记录不改写；改写技能不再套标准机制。普通分析补入非暗流的必要机制与相克，策略资料维持深度模式边界。报告一键回到记录、速记撤销与连续输入、流式局部更新，并收紧标题和历史行。180项检查与320/390像素回归通过。

v0.21将字数、耗时与停止合并到报告标题旁，取消冗余状态标签；按类型输出剩余名额与候选池，名额核验留在内部。补充多次占卜简写、共情历史邻座与猎手公开发动的整理，减少重复追问。172项检查通过，320/390像素隔离模拟验证；本轮未追加真实模型调用。

v0.20开始分析即打开流式报告，关闭后完成不打断记录。报告按确定/高概率及逐类全场候选组织；引入本局首夜/其他夜晚参考和死亡能力窗口，支持死亡触发、复活与重获能力，DIY顺序不强定。默认一次请求，关键冲突/候选遗漏才最多追加一次核对，不因长度加调用；165项检查通过。

v0.19在导入JSON右侧加入“图转json prompt”，复制识图转换要求与当前角色目录，其他AI可据剧本照片输出可直接导入的纯JSON。已有角色直接引用，本机自定义角色也可复用；新角色/技能改版完整保留，识别不清标待核对。复制失败手动回退并保留JSON草稿，155项检查通过。

v0.18新增常驻山雨欲来、华灯初上两份角色合集；实际访问220个角色页，整理221份角色资料，设置可查全库、剧本内点角色查详情。深度思考才附本局兼容版本的机制、答疑与策略，追问增量复用；普通分析保持简要输入。同名正式角色和尚/僧侣、隐士/陌客及新旧改版分别保存。149项自动检查通过。

v0.17增加常驻“补记录”，并对标准暗流的角色名额、唯一性、公开贞洁触发生成本地条件候选；只核算指定条件，不称完整世界穷举。保留v0.16的天亮死亡情况必选，取消不推进；玩家生死与角色标注改为号码旁的次级编辑，圆座位显示疑似角色。修复报告标题错位，分析按结论和座位候选归纳，补充本人行动与人数/男爵名额核验。保留此前修复：本人角色的私有视角优先级；默认V4 Pro快速，开始分析即打开流式报告。常驻库正确显示六份预装与自定义项，剧本名不附作者；历史对局显示开始时间到分钟。玩家窗口与线索列表更紧凑，关闭保存标注；刷新恢复当前局，旧线索和报告保留。角色别名兼容，标准名称为猎手、镇长、陌客、干扰项；手机系统强制挂起网页仍可能中断，重试由玩家发起。
