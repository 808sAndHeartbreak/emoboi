# 钟楼手记

血染钟楼玩家的记录与推理工具，移动端优先。

访问：https://emoboi.com/clocktower/

- 新建对局，选择剧本、人数、座位和自己的角色。
- 记录发言、行动与结果；天亮可批量记录死亡。
- 在设置里填写自己的 DeepSeek API Key、选择模型，随后一键分析或继续追问。
- 内置暗流涌动、梦殒春宵、黯月初升，支持自定义角色与剧本 JSON 导入/导出。
- 对局保存在当前浏览器；可导出、恢复完整备份。Key 默认仅本次打开有效，可选本机记忆，不进入备份。
- 同局每轮携带最新完整资料及最近 6 轮完整分析；修改与撤回优先，新局独立。

`index.html` 包含全部运行资源，下载这一份文件即可在本地浏览器打开。离线记录可用，AI 分析需要网络。此目录不包含密钥、个人对局或测试数据。

本地版与网站使用不同浏览器存储空间；需要在本地导出备份，再到网站恢复，并重新填写 Key。

UI v0.6：黑灰红、原创雕版钟楼和暗红月亮。玩家标记、线索录入、时间线与推理合并为一个工作台；规则与 API 放在设置，剧本配置放在开局流程。完整报告在阅读窗内展开，分析期间可以继续记线索。

字体：品牌/标题为 Noto Serif SC，正文/界面为 Noto Sans SC；许可见 [NotoSerifSC-OFL.txt](NotoSerifSC-OFL.txt) 和 [NotoSansSC-OFL.txt](NotoSansSC-OFL.txt)。字体与原创背景均已内嵌。游戏和角色内容属于各自权利方。
