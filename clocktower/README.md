# 血染钟楼推理工具

[打开工具](https://emoboi.com/clocktower/) · [当前推理架构](docs/reasoning-v29.md)

手机优先，兼容平板和电脑。首页开局后，在游戏信息页记录自称、发言、行动、生死及个人标记；推理分析页调用DeepSeek并查看报告。

## 使用

- 默认12人，支持5–20座位。选择剧本、本人座位与角色；历史对局可继续、删除或恢复。
- 默认V4 Pro、不深度思考，模型可切换。API Key在设置中自行填写或粘贴。
- 新分析独立使用最新完整资料；历史报告内追问沿所选对话，增量更新。流式结果逐段显示，费用只在详情末尾。
- 游戏信息页可直接打字速记、点座位写声明、修改自称、生死和标记，也可补记历史天夜。天亮必须选择死亡情况，关闭窗口取消推进。

## 剧本与角色

内置暗流涌动、梦殒春宵、黯月初升，常驻重见天日、山雨欲来、华灯初上。支持自定义角色、临时或常驻JSON导入导出。

角色详情提供机制、交互、问答与策略，深度思考才附本剧本进阶资料。保留221份资料与来源。自定义及改写技能以本局原文为准。猎手/镇长兼容杀手/市长；相近名称按本局角色池识别。

[JSON导入标准](docs/script-json.md) · [可导入示例](scripts/import-example.json)

## 当前版本

v0.29统一推理原则、报告和条件追问的保守约束，支持单夜限定、配比容量及合法登记；清理新请求中的旧锚点和重复检查。送葬续报、更正、跨夜和未解析信息采用安全的覆盖检查。274项自动检查及七段内联脚本构建校验通过。

局内采用中性黑、纸白、灰与暗红。自称使用黑白按钮；报告只列身份和机制变化，其他解释可展开。

## 数据与边界

数据按浏览器本地保存，可导出完整备份。Key不进入对局备份或分析资料。升级不删除、不自动重新请求历史报告。16–20座位需补充旅行者或特殊配置，僧侣不能选择自己。

静态暗流有界搜索与完整原文分析按覆盖范围切换；不把有限样例当穷举或统计概率。下载本目录`index.html`即可离线记录；AI需网络，手机系统回收网页可能中断，已有输出会保留。

字体为Noto Serif SC与Noto Sans SC，许可随站点提供。角色与游戏内容属于各自权利方。
