## 使用

1. 首页点击“开始”，选择剧本、人数、座位和自己的角色；对局名选填。历史对局显示剧本、名称、人数、阶段和开始时间（精确到分）。默认12人，支持5–20个座位；刷新可直接恢复当前局。
2. “游戏信息”中点击圆形座位写声明、标记或更新生死和自称角色，相关线索直接显示，点叉关闭即可。也可在下方打字速记；标题右侧“补记录”选择历史天/夜，草稿保留，保存不改变当前游戏阶段；历史线索采用紧凑行，右侧菜单编辑/删除。入夜记录处决或无人处决，天亮必须明确选择无人死亡、死亡玩家或沿用已记录死亡；关闭窗口取消天亮。
3. 设置中粘贴自己的DeepSeek API Key。推理页可选模型、思考模式及问题；新配置默认V4 Pro、不深度思考，已有选择保留。开始分析即打开流式报告；关闭后可继续记录，完成不抢回焦点。
4. 有重点问题时专项回答；未填写时按条件讨论主要可能，少信息简答。历史按对话归组，点进去可沿该分支继续，并补入最新线索。两页各自保留草稿和滚动位置，分析期间可切回游戏记录。

5. 导入JSON右侧的“图转json prompt”可复制转换提示词与当前角色目录。把提示词和剧本照片发给支持图片识别的AI，将纯JSON结果粘贴回来检查；已有角色直接引用，新建或改版保留完整技能。复制失败时可在原窗口手动全选，JSON草稿保留。

## 剧本与规则

- 内置暗流涌动、梦殒春宵、黯月初升；预装常驻[重见天日](scripts/daybreak.json)（北方的预言家，按提供图片整理），含25个玩家角色、2个奇遇及完整特殊规则。
- 常驻剧本库包含全部六份预装与本机自定义剧本；基础剧本可查看或编辑副本，自定义项可修改、删除或恢复。支持手动新建角色、粘贴或上传JSON、长期本地保存；剧本名称不附作者。
- 新增常驻[山雨欲来](scripts/storm.json)（25个角色）和[华灯初上](scripts/temple-fair.json)（27个角色，含旅行者和传奇）。两者是角色合集，保存完整池，开局可按实际剧本调整；新版/旧版戏子和禁卫军独立。
- 设置→角色资料可查221份资料；剧本信息里点角色查看机制、交互答疑、策略与伪装应对。资料来自实际读取的220个中文百科角色页，加一份改版卡面；按需展开、离线可用，各角色保留来源链接。部分原页没有进阶章节，按技能整理的建议会单独注明。
- [JSON导入标准与拍照流程](docs/script-json.md) · [可导入示例](scripts/import-example.json)。支持引用本机常驻剧本的自定义角色；同ID不同版本不随意复用，OCR待核对内容会在预览提示。
- 开局的临时JSON、角色调整及本局裁定仅用于当前对局；设置中的通用补充规则适用于每局。
- 16–20人局请补充旅行者或特殊配置，不根据总座位数套用常规阵营配比。

## 分析与数据

- 本人角色栏是私有视角前提，与其他玩家跳身份分开；本人对外声明不覆盖私有身份；夜内死亡与夜初存活分别记录，行动按当晚结算顺序判断。猎手/镇长兼容杀手/市长及常见简称。和尚（Heshang）与僧侣、隐士（Hermit）与陌客独立；只有本局没有同名正式角色时才采用旧俗称，明确旧ID仍兼容。定制技能以原文为准。
- 新分析默认开启独立对话，只用最新完整资料，不带旧报告；追问沿所选报告继续，无变化只加问题，有变化附增量。DeepSeek是无状态接口，仍需发送该对话的已有前缀，可利用前缀缓存。
- 深度思考才附本局角色池的机制、相关交互、问答和策略摘要，普通分析不附整套进阶资料。标准攻略不应用于改写技能；本局裁定优先，策略不是身份认证。追问首次开启时增量加入、后续复用；关闭后清理历史请求副本中的资料，原始快照不变。
- 分析显示实际连接、等待、思考与生成状态。断流或页面关闭后保留已收到的内容和草稿，不会自动重发付费请求；失败可手动重试。
- 分析时尝试保持屏幕常亮；手机系统强制挂起、回收网页或网络切换仍可能中断，无法保证锁屏后后台完成。
- 对局、草稿和剧本库保存在当前浏览器，可导出和恢复完整备份。设置中的“退出本局”返回首页，记录仍保留。
- Key默认仅本次打开有效，可选在本机记住；不进入对局备份、分析资料或导出文件。本地版与网站存储独立，迁移需导出备份并重新配置Key。

`index.html`包含全部运行资源，下载这一份文件即可在浏览器打开。离线记录可用，AI分析需要网络。本目录不含凭据、个人对局或测试数据。
