# 钟楼手记

血染钟楼玩家的记录与推理工具，移动端优先。

访问：https://emoboi.com/clocktower/

- 首页点击“开始”，选择剧本、人数、座位和自己的角色，或展开开局窗口的“历史对局”返回旧局。
- 记录发言、行动与结果；天亮可批量记录死亡。
- 在设置里填写自己的 DeepSeek API Key、选择模型，随后一键分析或继续追问。
- 内置暗流涌动、梦殒春宵、黯月初升，支持自定义角色与剧本 JSON 导入/导出。
- 对局保存在当前浏览器；可导出、恢复完整备份。Key 默认仅本次打开有效，可选本机记忆，不进入备份。
- 同局每轮携带最新完整资料及最近 6 轮完整分析；修改与撤回优先，新局独立。
- 通用规则补充和常驻剧本库位于设置。常驻剧本支持手动新建、编辑技能、导入 JSON 和长期本地保存。
- 开局的临时 JSON 与本局裁定仅作用于该局，不覆盖剧本库。历史对局、自定义剧本可删除和恢复。
- 设置中的“退出本局”返回首页，保留对局和线索草稿。玩家、记线索与推理位于同一工作台；线索和分析历史分别在对应分组内折叠。

`index.html` 包含全部运行资源，下载这一份文件即可在本地浏览器打开。离线记录可用，AI 分析需要网络。此目录不包含密钥、个人对局或测试数据。

本地版与网站使用不同浏览器存储空间；需要在本地导出备份，再到网站恢复，并重新填写 Key。

UI v0.10：更强的逐字拼贴标题上移，大号“开始”按钮与下方“设置”按钮条组成首页操作区。开始后直接配置新对局，默认 12 人、支持 5–20 座位；加减按钮快速调整，点击数字可输入。默认暗流涌动，剧本列表折叠显示，选定后自动收起。

“自定义剧本”可选择角色、创建角色或导入 JSON，内含可填入的格式示例。当前剧本角色默认全选；开局切换只更新相关字段并保留各自修改。角色编辑窗口维持稳定尺寸，只滚动角色列表，返回编辑后保留搜索，新角色自动定位。

游戏顶部合并为剧本标题与阶段操作；设置和对局菜单合并。玩家均衡排布，每行最多 5 人，12 人为 4×3；淡绿表示存活、红色表示死亡。直接打字、记下即可保存，历史线索可展开编辑或删除。推理区显示当前模型、选填问题、开始分析及折叠历史，无底部跳转栏。已完成报告优先展示正文，普通分析与追问分别标记，历史报告保留实际使用的模型。

16–20 人局可能包含旅行者或特殊配置，不根据总座位数自动推定常规阵营配比；请在本局规则中补充。记录和分析保留原有上下文、备份与撤回机制。

推理区分公开观察、条件硬约束与行为倾向，按当前剧本补充间谍误登记、二选一指认、占卜判定范围等交互校验。报告用结论、候选逻辑、验证顺序组织，明确支持/排除方向，角色池不代表在场名单，最新修订优先。真实 Flash / V4 Pro 虚构对局测试用于发现并修正提示问题；模型列举代表分支，不冒充穷举证明。

字体：品牌/剧本标题为 Noto Serif SC，首页标题与正文/界面为 Noto Sans SC；许可见 [NotoSerifSC-OFL.txt](NotoSerifSC-OFL.txt) 和 [NotoSansSC-OFL.txt](NotoSansSC-OFL.txt)。字体与原创背景均已内嵌。游戏和角色内容属于各自权利方。
