## 使用

直接打开 **钟楼手记.html**，无需安装或构建。单文件约 2.5 MB，字体、原创背景、样式和脚本均已内嵌。记录可离线使用，AI 需要网络。

1. 点击“开始”，新建对局并选择剧本、人数、自己的座位和角色；或在“历史”返回之前的对局。
2. 直接写下“3号自称厨师，首夜0”等发言、行动或结果，点“记下”。点玩家可直接写声明或确认死亡。入夜记录处决，天亮批量记死亡；历史线索可编辑或删除。
3. 设置中粘贴自己的 API Key；切到“推理分析”选择模型、开始新分析，或打开历史对话继续追问。

支持暗流涌动、梦殒春宵、黯月初升、重见天日、山雨欲来、华灯初上，以及 JSON 文件/粘贴导入、自定义角色。支持 5–20 个座位；16–20 人局请在本局规则中补充旅行者或特殊配置。

## 数据与推理

- 对局和草稿保存在当前浏览器，可导出/恢复完整备份；旧版 v1 数据继续兼容。
- API Key 默认仅本次打开有效，可选本机记忆；不进入对局备份、快照和请求导出。
- 新分析仅用最新完整资料；追问沿所选报告继续并增量补充变化，编辑和撤回可重建为当前资料。旧 AI 结论不是证据。
- 公开事件、本人反馈、他人自述与个人推测分开。公开死亡、复活、幽灵票和身份变化可追溯；处决不自动等于死亡。
- 报告的“查看分析依据”展示分析时的原始记录版本，内部编号不在正文显示。
- 本地文件和网站的浏览器存储互相独立。换设备或迁移到网站前先导出备份，随后恢复并重新配置 Key。
