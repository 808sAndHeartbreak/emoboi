# v0.22 统一信息入口与推理流程

## 信息进入分析

自由速记中以“n号”开头的明确玩家发言可关联座位，明确声明则关联角色。新速记保存时采用同一解释；旧记录只生成读取投影，不改写原文、ID、来源或时间。投影供玩家座位、相关线索、数字联立和条件名额核算使用。

个人推测、说书人公告、已明确的记录对象、身份否定和关于他人的转述不擅自变成真实角色。角色声明始终不是身份认证，本人私有身份仍单独采用。修改、撤回和补记重建派生信息，不改旧报告的证据快照。

## 规则与世界约束

标准机制检查、报告复核与角色版本标记统一核对技能、类型和兼容版本；不能仅靠角色ID，把改写技能套入原版检查。普通分析附当前角色池兼容版本的必要机制及相关相克，去除重复相克；暗流已有专门核验的机制不重复附完整摘要。改写技能、本局裁定优先。答疑、技巧与伪装策略仍只在深度模式提供。

提示词采用通用的条件约束流程：先区分谁在何时具备能力、选择范围与次数，再区分发动、实际效果、收到反馈和反馈真实性。成功与无效果不能简单互为逆命题；不要求玩家提供技能没有告知的隐藏内容。候选世界同时联立已采信息、开局配额、逐夜状态和失真来源容量，避免独立可行候选任意拼接。只在合法世界之间比较优先级，保留真正影响决策的代表分支。

仍采用一次流式分析，默认新分析仅在明确的关键矛盾/必要候选遗漏时最多追加一次核对；专项和追问不固定增加调用。没有引入额外准备轮或输出检查过程。

## 操作与阅读

- 报告顶部一键“记线索”，保留草稿和当前报告阅读位置。
- 速记保存后继续输入；提供撤销，误保存后恢复文字草稿。已有文字不会被撤销操作覆盖。
- 流式输出只更新变化节点，已完成段落不整块重建，减少重排和选择文字被打断。
- 报告分支标题、行动区、历史行与按钮层级更紧凑，键盘焦点清晰；失效提示不留下隐藏可点击按钮。

## 验证

185项自动检查通过，覆盖自由速记、私有视角、公告/转述/推测边界、补记和更正、公开触发与配额联立、技能改写、普通/深度资料边界、跨局隔离及既有API流式处理。隔离浏览器验证速记关联、撤销恢复草稿、保存继续输入、报告返回记录与完整流式分组；320px和390px无报告横向溢出。单文件内联脚本及离线资源依赖检查通过。

这些检查验证资料处理与已实现的条件约束，不构成所有角色组合的完整求解器，也不能证明LLM的每份输出正确。

## 实测后的补修

修复“5、6、10号”被错当有序列表导致首个号码消失的排版错误。压缩重复候选矩阵，将本地正常信息条件分支置于输入前部，明确全部身份前提、登记条件和精确联立结果；撤销前提时不能搬用原分支锁定。假身份不代表所报数字必假，常见合法登记本身不构成低概率依据。新增对应复核；最多一次复核后仍有明确冲突，报告折叠标出待核对，不再循环调用。
