# v0.29 · 当前推理架构

## 当前入口

记录 → 来源与夜次编译 → 覆盖检查 → 静态暗流核验或完整原文分析 → AI分类/专项回答 → 校验与流式展示。

`inference.js`维护一份当前推理原则和保守约束推导。`reasoner.js`负责标准暗流的组合搜索、目录和报告协议；`core.js`负责记录、编译及其他场景的原文请求。应用新快照、复制和分析入口均采用当前协议。旧构造器、旧校验和旧文档只保留历史兼容及旧回归用途，不再进入新原文请求。

## 本轮修复

- 报告的恶魔范围和追问曾分别实现。现在都调用同一域传播模块：私有身份、采信的技能反馈、角色唯一性、静态恶魔位置与起始配比。配比使用容量匹配条件核验，并区分男爵是否实际占一个爪牙位，不能用“可能有男爵”容纳已经塞满的其他爪牙。
- 追问的`normal`不再仅按两个主信息角色的粗分类判断。支持`night`限定某夜，未指定才涵盖所列反馈；真实角色不自动正常。复合否定不翻转为一组肯定条件。前提矛盾和缺少该夜记录分别处理。
- C8D51394中，送葬、共情和占卜均真实且反馈正常时，可以由硬约束证明2号小恶魔；报告与追问一致。只采信送葬第二夜正常，不能偷换成第三夜也正常并锁定10号陌客。
- 修复中毒组合只截取最后三夜的旧限制。四夜内完整保留被编译的夜次；更长的状态组合交给完整原文分析，保留早期记录，不拿被截断的模型排除合法解释。
- 送葬支持单次续报、逐夜口述、结构化反馈、明确更正；洗衣妇支持分隔和紧凑号码。不能对应的结果、未建模的信息能力或明确承认伪报，会走原文路径，避免忽略记录后继续展示局部核验组合。
- 当前原文请求移除旧局锚点、重复核验清单、配额匹配样表和旧格式强调。保留私有视角、原话、角色技能、必要机制、夜序及可编译信息。原文复核复用同一推理原则；新分析独立，追问只沿所选对话增量更新。
- 真实接口实测发现模型可能给完整JSON Lines套代码围栏，旧解析会误标未完成并产生额外修复调用。现在只容忍围栏包装，仍校验每个对象、引用及覆盖；流式包装不显示。仅因围栏误标且接口明确stop的旧报告可本地恢复完成状态，保留原文及费用，截断或中断不冒充完成。
- 快照指纹包含推理版本，旧结果不会被当成当前逻辑的新结果。升级不删除或自动重跑历史报告。损坏的目录显示可理解的提示，避免白屏；空格式输出进入一次格式修复。

## 阅读与交互

主界面延续钟楼拼贴。局内以中性黑、纸白和灰作层级；暗红用于主要动作和危险含义。“自称”是黑白工具按钮，普通号码与角色不再普遍染红紫。衬线用于大标题，正文用黑体，号码与百分比用等宽数字。身份变化继续按来源首组比较；投毒和干扰项也只写变化，类标题已有唯一恶魔结论时不在每个子标题重复。

玩家按钮保留44px触控高度。流式追加、折叠展开与完成重绘保留阅读位置；支持减少动态偏好。无需引入WebGL或新的远程依赖，独立HTML仍离线记录可用。

## 范围与验证

274项自动检查通过，包括两个用户案例、跨夜与更正、首夜中毒保留、配比容量、正常性与复合否定、合法见证的交叉核验、损坏目录、空输出、上下文增量和既有回归。七段内联脚本单文件构建校验通过。

保守域传播不是完整求解器：它可以证明其约束支持的必要结论，也可以用核验组合给出存在例或反例；没有找到组合不作排除，样例数量不作概率。静态暗流搜索仍有预算边界，身份传承、主动伪报和未建模技能不冒充全时序穷举。完整原文路径保留模型分析能力，不具有同等形式保证。实际接口和响应式结果另记于QA。
