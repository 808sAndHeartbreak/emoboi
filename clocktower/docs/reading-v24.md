# v0.24 · 更少干扰，更快阅读

费用只在所选报告详情的末尾显示小号人民币金额，不再出现在历史列表、报告顶栏、历史快照列表；移除“粗估”“约”、用量块和费用说明。底层用量、缓存、复核账目与备份兼容保留，未知费用不显示成零。

报告的阶段与类型合入窗口顶栏；模型和时间只出现一次，资料更新提示缩成行内状态。正文之后是追问、折叠历史与资料、末尾费用。对话列表仅保留题目、日期、轮数及异常/生成状态，正常项用箭头进入。

手机：单列，收紧圆桌与表单间距，保留44像素起的座位触控区。760像素起圆桌与记录并排；1024像素起分析表单与历史并排。设置保留连接主区，将本局规则、通用规则、剧本库与备份整合为连续分区。输入保持16像素，使用安全区、动态窗口高度和减少动态效果偏好。

视觉采用炭黑、暗红、暖纸色，标题保留衬线字体，信息与操作使用无衬线；减少阴影、紫色边框和重复容器。首页拼贴与钟楼背景保留。
