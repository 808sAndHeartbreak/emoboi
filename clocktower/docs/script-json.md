# 剧本 JSON 导入标准

使用 UTF-8 JSON 数组，第一项是 `_meta`，后续每项是一个角色。不要加入 Markdown 围栏、注释或额外文字。最多250项，包含元数据。

```json
[
  {"id":"_meta","name":"我的剧本","specialRules":""},
  {"id":"monk"},
  {"id":"imp"},
  {
    "id":"custom_nightwatch",
    "name":"巡夜者（自制示例）",
    "team":"townsfolk",
    "ability":"每个夜晚，你会得知当晚是否有玩家改变了阵营。"
  }
]
```

- `_meta.name`：剧本名，不拼接作者；`author`可选，`specialRules`记录图片明确给出的额外规则、相克或版本说明。
- 已有角色：只写`id`，直接引用工具的定义。复制的图转提示词会自动附上当前内置角色及本机可唯一引用的自定义角色目录，不需要记英文ID。
- 新角色或技能改版：完整填写`id`、`name`、`team`、`ability`；推荐唯一`custom_`前缀。`notes`可选。改版不得用原角色ID覆盖原技能。
- 类型：`townsfolk`镇民、`outsider`外来者、`minion`爪牙、`demon`恶魔、`traveler`旅行者、`fabled`传奇、`loric`奇遇。
- 同名不等于同角色。和尚/僧侣、隐士/陌客、食人魔/食人族，以及戏子/禁卫军的新旧改版应按技能区分。
- 本机多个自定义角色如果共享同一ID却有不同定义，不提供简写引用，需输出完整的新ID版本。内置ID始终引用标准角色，不被本机同ID改写遮盖。
- 看不清的新角色技能不得猜填；省略不完整条目，并在`specialRules`写“待核对：位置及缺失信息”。预览会提示检查。完全无法识别角色时应让AI返回`[]`，工具会拒绝空剧本。
- 原有标准连写英文ID、中文角色名及兼容别名导入方式继续可用。对象形式`{"roles":[...]}`也保留兼容；图转输出统一采用上述数组形式。

## 手机拍照流程

1. 在导入JSON右侧点“图转json promp”，自动复制提示词。
2. 将提示词粘贴到支持图片识别的其他AI，并附剧本照片；可一次提供多张图。
3. 将AI输出的纯JSON粘贴回来，点“检查并预览”，核对后用于本局或存入剧本库。

复制只包含转换要求和角色目录，不含API Key、玩家发言、座位、本人信息或对局记录。不调用本工具的LLM接口。浏览器禁止自动复制时会在当前窗口显示可全选的提示词，保留原JSON草稿。

## 验证

155项自动检查通过，包含全部221个内置ID逐项导入、自定义角色简写引用、版本冲突、完整改版、待核对、草稿保留和现有功能回归。浏览器检查包含正常剪贴板复制、强制拒绝复制后的手动回退、320/390像素排布和粘贴预览。外部AI的图像识别结果仍需在预览中核对。
