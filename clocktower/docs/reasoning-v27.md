# v0.27 · 联合约束与结构化报告

## 上版没有解决到位的部分

原始请求约2.47万字符，规则、机制提醒与检查要求多次重复。v0.26又加入大量配额匹配材料，但配额可匹配不等于完整技能同时成立。模型需要自行把中文叙述转换为夜次、判断角色真假、找组合、检查组合并写报告；自由正文允许它在子类推翻父类。正则复核只能发现部分措辞错误，不能证明一个世界成立，重复调用同一模型也可能复制错误。

## 新流程

1. 保留原话与来源，单独编译人物自称、客观事件、私有视角、行动结果和历史窗口。自己对外的假报不覆盖私有角色，也不自动当作本人收到的真实技能反馈。未指定玩家的原话不擅自关联座位。
2. 用正常/具体夜次投毒/酒鬼/邪恶假跳/善良穿衣服区分两个主要信息轴；在每个条件类内搜索完整身份组合，再联合其余已解析信息，而非只核验这两名玩家。
3. 每个可展示组合检查起始人数、角色唯一性、私有身份、成功贞洁触发、送葬登记、洗衣妇二选一、共情历史邻居、厨师邪恶邻接、占卜固定善良干扰项、投毒来源与同夜容量；同时检查常见圣徒处决、士兵夜死与猎手无效果等限制。
4. 在搜索结果中保留不同配比、恶魔位置、真假角色和投毒夜次的代表。保留男爵、双邪恶假跳与送葬第三夜中毒等不同解释，避免按搜索顺序只抽取同一种世界。
5. AI收到精简事实、原话、必要技能、历史夜序、已核验组合目录和可执行的问题目录。它选择代表、排序主观权重和决定下一步，不能在默认报告中另造身份表、配额或历史邻居。
6. 输出为JSON Lines。前端逐段检查引用后显示中文报告，编号与JSON碎片不进入正文；固定结论、剩余名额和具体座位从本地数据生成。后续组合只列相对首组合的身份变化，避免重复全表。

模型输出不能改变已核验世界。例如引用“6号真送葬”的组合后，即使另加一份“6号恶魔”的自由身份表，该字段也不会显示；引用不存在的世界或跨类世界会被拒绝。格式不完整最多快速修复一次，不自动反复重跑整局。

## JSON职责

- `perspective`：本人私有角色与状态，不再作为报告开头复述。
- `evidence`：带来源的原始记录；死亡座位是`subjectSeat`，说书人是公开事件来源。
- `information`：派生的行动夜次、反馈、目标和历史邻居，包含原记录引用。原话仍可核对。
- `rules`、`nightOrder`：本局技能与必要规则。深度模式另附角色进阶资料。
- `families`：互斥信息状态类、条件固定角色、剩余名额与保守候选边界。
- `worlds`：联合检查过的完整身份组合、固定干扰项与具体投毒日程。
- `actions`：真正缺失的信息。例如样例缺少5号和12号第三夜结果，已有的送葬与共情邻居不再重复询问。
- `search.complete`：搜索是否完整。当前明确为false，不能把样例数量当概率或认证唯一解。

新分析不带旧报告。新协议追问保留所选对话并只增量发送变化；撤回或编辑会更新证据及组合目录。旧版对话可迁移一次，旧报告仍是讨论材料，不是新证据。复制最新资料、保存快照和导出请求使用同一入口，避免网站与外部测试拿到不同提示词。

## 展示与边界

整理线索、连接、等待、思考、输出分别显示实际阶段。收到完整可核验的一段就显示一段，页面不显示内部思考正文或未闭合的JSON。断流保留已完成的有效段。概率是主观权重，界面不把它写成统计概率；费用仍只在详情末尾。

求解器当前覆盖标准暗流的已实现约束，采用有上限的搜索；它不等于所有技能、所有历史变化的完整穷举。未记录的保护、传位、改口/善良主动谎报、未解析行动等仍有未覆盖情况。无代表组合不等于该类不可能，界面明确保留待搜索类。特殊裁定、改写技能及其他剧本保留模型分析路径，不冒用标准暗流规则做硬排除。专项自由问答与外部Markdown仍不是形式证明。

238项检查及单文件构建校验通过，包含原样例联合验证、私有反馈与公开假报分离、状态继承、跨类引用拒绝、半段流式不泄漏、上下文增量和取消。真实接口与响应式结果记录在QA中。


实测：实际请求15915字符，6段模型输出478字符，界面报告1544字符。候选目录24份逐一通过本地已实现约束，正文没有基础身份复述。实测后的优化进一步优先少失效假设、个人标记与夜死软倾向，并补足间谍登记代表；均不按样例频次计算概率。信息很少时只短答，不强行展示全场身份表。



补充边界检查：间谍/陌客自身中毒时不能继续提供误登记；真实身份仍可正常被得知。代表搜索优先不额外调用醉毒解释，必要时才加入；保留不含醉毒的间谍登记分支。
