# v0.26 · 流式报告与交叉推理

手机后台或锁屏恢复后，按实际经过时间核验等待上限；接口心跳不再无限延长等待。断流保留收到的正文，不自动重发。普通分析严格关闭思考，只有手动开启才使用深度模式。发现语义错误时最多快速复核一次，上限60秒；复核中实时显示正文，失败保留首次报告。移动系统仍可能挂起或回收网页，不能保证锁屏后台完成。

玩家角色标注统一为“自称”，手工记录与发言识别进入同一分析入口，但不认证真实身份、不覆盖本人私有角色。补齐中文数字、重复声明前缀、洗衣服别名、连续两晚共情及送葬反馈的对应。

本地准备交叉关键角色的正常、中毒夜次、酒鬼、邪恶假跳及善良穿衣服状态，检查名额、唯一角色、同夜投毒容量与相关登记。它是部分约束剪枝，并非全技能、全时序世界穷举；未覆盖的交互仍由模型联合检查。

报告只保留新推导，避免复述本人身份、死亡时间线、幽灵票或未发生的机制。大类按主观权重降序，标题显示百分比；必要时分撒谎与具体失真子类，逐类覆盖座位和剩余名额。百分比不是统计概率，不按代表方案数量计算。

用户样例回归发现：6号送葬与12号共情均正常时，10号可为陌客，向送葬登记男爵、向共情登记善良。测试保留此合法分支，并验证双酒鬼、同夜双毒等不合法组合被排除。处决不会自动公开真身份。

新增父类固定身份与子类候选冲突检查；将逐夜共情邻居写入明确约束并检查历史窗口，防止用后来处决倒改。逐分支记录撤销的自称，避免已判为陌客者仍贡献真厨师技能约束。快速复核统一不思考，独立60秒上限。
